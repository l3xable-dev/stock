## ຄຸນສົມບັດ
- ທຸກເຄື່ອງເຫັນຂໍ້ມູນຊຸດດຽວກັນ (Apps Script + Google Sheet)
- ເນັດຂາດກໍ່ແກ້ໄດ້ ແລະ ສົ່ງຂໍ້ມູນເອງເມື່ອເນັດກັບມາ
- ປະຫວັດການເຂົ້າ-ອອກແບບ net ຕໍ່ວັນ + ບອກວ່າເຄື່ອງໃດແກ້
- ຕັ້ງເກນເຕືອນສະຕັອກໜ້ອຍ, ຍ້າຍລຳດັບສິນຄ້າ, ປ່ຽນຊື່ສິນຄ້າ
- ລາຍງານປະຈຳວັນ + ພິມ/ບັນທຶກ PDF + Export CSV/JSON
- ລະຫັດ PIN ລັອກໜ້າຈໍ (ທາງເລືອກ)
