# TIBKAO STOCK (app ສະຕັອກຮ້ານ)

ແອັບຈັດການສະຕັອກແບບ offline-first ທີ່ໃຊ້ຂໍ້ມູນຮ່ວມກັນຜ່ານ Google Sheet.

## ເປີດໃຊ້
https://l3xable-dev.github.io/stock/

## ຄຸນສົມບັດ
- ທຸກເຄື່ອງເຫັນຂໍ້ມູນຊຸດດຽວກັນ (ຜ່ານ Apps Script + Google Sheet)
- ເນັດຂາດກໍ່ແກ້ໄດ້ ແລະ ສົ່ງຂໍ້ມູນເອງເມື່ອເນັດກັບມາ
- ບັນທຶກປະຫວັດການເຂົ້າ-ອອກ ແບບ net ຕໍ່ວັນ
- ລາຍງານປະຈຳວັນ + ພິມ/ບັນທຶກ PDF + Export CSV/JSON
- ລະຫັດ PIN ລັອກໜ້າຈໍ (ທາງເລືອກ)

ຢ່າແກ້ໄຂດ້ວຍມື — ໃຫ້ສ້າງໃໝ່ຈາກໄຟລ໌ຕົ້ນສະບັບ.
